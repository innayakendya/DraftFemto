# DraftFemto

Watches Ethereum blockchains and relays transaction data to a user-friendly interface for real-time tracking.

The key benefits of using DraftFemto include:

- Watches Ethereum blockchains and relays
- transaction data to a user-friendly
- interface for real-time tracking

## Key Features

- Watches Ethereum blockchains and relays
- transaction data to a user-friendly
- interface for real-time tracking

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftFemto.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
